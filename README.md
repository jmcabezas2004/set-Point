# Set Point · Somos tenis de mesa

Web de Set Point, la tienda física y online especializada en tenis de mesa para jugadores y clubes de Andalucía occidental (Proyecto Integrado · MAPU · Curso 26/27).

Es una web estática (HTML, CSS y JavaScript, sin dependencias ni compilación):

- `index.html`: contenido y estructura.
- `css/styles.css`: estilos y colores de marca (rojo `#D30B25`, negro `#14171D`).
- `js/main.js`: interacciones (peloteo animado, marcador de scroll, tienda con filtros y carrito, blog, asesor de material, embudo, DAFO y minijuego «Torneo a 3 puntos»).
- `assets/img/`: logo, fotos y productos de la tienda Set Point.

Para verla basta con abrir `index.html` en el navegador. Para publicarla gratis, activa GitHub Pages desde la rama principal.
